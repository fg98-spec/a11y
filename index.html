ABOUT & DEPLOY

关于幕间 · 云构建部署

幕间是一个免费开源的观影导航应用：无广告、无会员、无追踪。片单与历史仅保存在你的浏览器 localStorage 中。

① 片源说明

所有「播放」按钮均跳转 v.qq.com 腾讯视频官方页面。免费内容可直接观看，会员内容遵循官方规则；本应用不提供任何解析、下载或去广告服务，评分为社区口碑参考。

② GitHub Actions 云构建（3 步上线）

  1. 把本项目推送到 GitHub 仓库的 main 分支（已内置 .github/workflows/deploy.yml）。
  2. 仓库 Settings → Pages → Build and deployment → Source 选择 GitHub Actions。
  3. 每次 push 自动云构建并发布，访问 https://用户名.github.io/仓库名/；页脚构建号实时点亮。
